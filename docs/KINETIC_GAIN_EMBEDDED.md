# Kinetic Gain Embedded Tie-Back

This repo demonstrates the AWS managed-threat-detection control-plane shape of Kinetic Gain Embedded:

- operator-safe visibility into detector coverage, credential abuse, runtime compromise, and data-exfiltration posture
- remediation packets that keep SOC, platform, and governance teams aligned on the same evidence
- a path from backend GuardDuty analysis into an embedded control-plane UI

For embedded product work, the same primitive becomes an in-app AWS security, SOC, or incident-response panel where operators need evidence-rich triage without direct access to raw GuardDuty consoles or cloud credentials.
